# Security

If you find a security problem in the code of this repository, please report it privately through GitHub's "Report a vulnerability" button on the Security tab rather than a public issue.

For a problem in one of the vendored mods, please also report it to the upstream project (links in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)); I will re-vendor the fix.

What each mod runs and reads is described in [docs/SECURITY-AUDIT.md](docs/SECURITY-AUDIT.md).
